# Прототип New Tone School

Статическая витрина перед разработкой: 13 экранов мини-аппа и 17 страниц админки,
связанных ссылками. Бэкенда нет, данные в разметке.

- `index.html` — стартовая страница со всеми переходами
- `app/` — Telegram Mini App (mobile, максимум 460px)
- `admin/` — веб-админка (desktop)
- `assets/style.css` — единственный стиль, токены бренда наверху файла

Бренд: фиолетовый `#462483`, жёлтый `#FFCC00`, Montserrat.
Мини-апп подключает `telegram-web-app.js`, поэтому внутри Telegram подхватит тему.

Содержание экранов — `../Бот/Постраничный сценарий — веб и мини-апп.md`.
